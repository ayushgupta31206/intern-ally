# Fix the survey-completed route (Not Found)

## Problem

The nav in the admin shell links to `/admin/survey-completed`, but no route exists at that path. The route file was committed via GitHub at the wrong nested location:

```
src/routes/_authenticated/admin/src/routes/_authenticated/admin/survey-completed.tsx
```

Because of the nested folder, TanStack Router generated a bogus route ID — `/_authenticated/admin/src/routes/_authenticated/admin/survey-completed` — which serves the URL `/admin/src/routes/admin/survey-completed`, not `/admin/survey-completed`. So clicking "Survey Completed" in the nav hits a path with no matching route and shows Not Found.

## Fix (3 steps)

1. **Move the file** to the correct flat location:
   `src/routes/_authenticated/admin/survey-completed.tsx`
   (delete the old nested file).

2. **Fix the `createFileRoute` string** inside the file from:
   `createFileRoute("/_authenticated/admin/src/routes/_authenticated/admin/survey-completed")`
   to:
   `createFileRoute("/_authenticated/admin/survey-completed")`

3. **Regenerate the route tree.** `src/routeTree.gen.ts` is auto-generated by the TanStack Router Vite plugin — it regenerates on the next dev-server restart / build. No manual edit to `routeTree.gen.ts` is needed (and must not be hand-edited).

## Result

The `/admin/survey-completed` link in the admin nav resolves to the real route, the page loads, and the stale bogus route entry disappears from the generated tree.

## Notes

- The rest of the file body (query, search filter, layout) is correct and stays unchanged.
- No other routes are affected.
